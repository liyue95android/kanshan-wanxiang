# 看山万象档案馆：HTML 可玩原型

跟着刘看山，走进一场知识冒险。玩家选择职业和答题路线，在一局中收集、升级五件自动生效的奇物，完成 15 道题并解锁万象档案。

## 运行

直接双击 `index.html` 即可运行。也可以在本目录启动任意静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

推荐使用 1440×900 或更高分辨率的桌面浏览器，最低目标分辨率为 1280×720。

## 原型内容

- 15 个答题节点的完整单局
- 6 种职业装扮的刘看山
- 8 个动作状态的全程向导燕鸥小姐
- 18 件奇物，最高 3 级，最多装备 5 件
- 5 种主动道具
- 6 个选择型事件
- 18 个知识组、54 道分级测试题
- 6 个代表性结局与本地万象档案
- 本地存档导入、导出

完整规则、数据结构与后续内容目标见 [GAME_DESIGN.md](./GAME_DESIGN.md)。

## 文件

- `index.html`：页面结构
- `styles.css`：横屏三栏视觉与动效
- `app.js`：游戏数据、状态机和规则实现
- `GAME_DESIGN.md`：玩法与世界观设计文档
- `assets/characters/`：刘看山职业图集与燕鸥小姐引导图集

## 题库说明

原型题目沿用已有题库的知乎来源链接。玩家作答后可查看简短解析，并打开对应知乎讨论。原型中的第三难度变体用于验证“推理型难题”方向；完整生产题库仍需逐条内容审核。
