# 刘看山与燕鸥小姐角色资源

本目录包含《万象档案馆》第一批角色拓展资源。

## 最终资源

- `liukanshan-careers.png`：六职业刘看山透明图集，3×2 排列。
- `miss-tern-guide-v2.png`：八动作燕鸥小姐最终透明图集，4×2 排列；依据新增四视图补齐羽冠和眼部睫毛。
- `miss-tern-guide.png`：首次生成的燕鸥小姐图集草案，保留用于版本对比。
- `roles/`：六张 512×512 独立职业 PNG 原始切图。
- `roles-v2/`：网页使用的六张标准化职业 PNG；统一可见宽高和脚底基线，并对原图宽度做轻量校正。
- `guide-v2/`：八张 512×512 最终独立引导动作 PNG。
- `guide/`：首次生成的八张独立动作草案。
- `source/`：内置图像生成工具输出的纯洋红抠图源图。

网页中的刘看山使用 `roles-v2/` 独立图，避免图集裁切产生的位置误差；燕鸥小姐仍使用图集。`roles/` 独立 PNG 保留用于后续单图调整、宣传物料和结局插画。

## 生成方式

使用 Codex 内置图像生成工具生成，参考项目中的 `刘看山四视图.png`、`燕鸥小姐.webp` 以及用户提供的刘看山职业盲盒图片。生成时使用纯 `#ff00ff` 背景，再通过 imagegen 技能的 `remove_chroma_key.py` 转换为透明 PNG。

### 刘看山最终提示词

创建精确 3×2 排列的六个全身刘看山职业角色：研究员、旅行者、银行家、工程师、侦探、收藏家。严格保留白色长鼻犬形头部、尖耳、黑色椭圆鼻、点状眼睛、细黑腿和圆尾；全部保持相同角色比例并朝左侧三分之二视角。职业分别使用研究护目镜与记录板、橙色围巾与指南针、礼帽与账本、格纹工作服与测量工具、猎鹿帽与放大镜、贝雷帽与六色徽章册。采用彩色扁平 2D 网页游戏画风、粗黑轮廓、克制配色；无文字、无底座、无阴影；纯洋红抠图背景。

### 燕鸥小姐最终提示词

创建精确 4×2 排列的八个全身燕鸥小姐引导动作：欢迎、普通讲解、指向路线、答对认可、答错记录、冒险警告、奇物／商店介绍、结局归档。严格保留圆润鸟形、近黑上半身、白色下半身、左侧橙色三角嘴、两只短橙脚、白边青色圆眼和灰色翅膀线；通过翅膀方向、身体倾斜及少量无文字道具表达动作。性格冷静专业、略带轻微吐槽；彩色扁平 2D 网页游戏画风、统一粗轮廓；无衣服、无人形手臂、无文字、无阴影；纯洋红抠图背景。

新增四视图后进行身份修订：保持八个动作、道具、比例和 4×2 布局完全不变，只为每个动作补上头顶单根黑色羽冠，以及青色眼睛外上缘的白色睫毛尖；继续保持侧面单眼结构，不增加多余眼睛。
